# USTED Counselling Management System: Staff Handover Guide

Welcome to the new **USTED Counselling Management System**. This guide will help you get started quickly.

## 🚀 How to Start the System

### For Windows Users:
1.  Open the folder **USTED_Counseling_System_Distribution**.
2.  Double-click **USTED_Counseling_System.exe**.
3.  The system will start, and your web browser will automatically open to the Dashboard.
4.  *(Optional)* Run **Create_Desktop_Shortcut.bat** to place a shortcut on your desktop for easy access.

### For Mac Users:
1.  Open the folder **USTED_Mac_Version**.
2.  Right-click **INSTALL_AND_RUN.command** and select **Open**.
3.  The system will configure itself and launch in your browser.

---

## 🖥️ Using the Dashboard
- **Access URL**: `http://localhost:5000`
- **Navigation**: Use the sidebar to access Students, Appointments, Reports, and the Map.
- **Printing**: Click the "Print" button on any record. The system will generate a professionally branded **USTED** document.

---

## ☁️ Cloud Sync (Cloud Bridge)
The system is designed to work **offline**, but it syncs with the cloud whenever an internet connection is available.
- **Check Status**: Look at the "Sync Status" at the bottom of the dashboard sidebar.
- **Green**: Data is successfully backed up to the cloud.
- **Red/Yellow**: System is waiting for a connection or sync is disabled.

---

## 🛠️ Troubleshooting
- **Browser doesn't open?** Manually type `http://localhost:5000` into Chrome or Edge.
- **Data not syncing?** Ensure you have an internet connection and the "Sync Enabled" toggle is ON in the Settings page.
- **Need to restart?** Close the application window and run the `.exe` (Windows) or `.command` (Mac) again.
